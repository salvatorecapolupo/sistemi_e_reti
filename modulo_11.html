Modulo 11: NAT e PAT

Network Address Translation e il salvataggio degli indirizzi IPv4

Cos'è il NAT?

Il NAT è una tecnica che permette di modificare l'indirizzo IP nell'header di un pacchetto mentre attraversa un router. La sua funzione principale è permettere a una rete privata (con IP non instradabili su Internet) di accedere alla rete pubblica usando un unico (o pochi) IP pubblici.

Problema: Esaurimento indirizzi IPv4.
Soluzione: Migliaia di host privati "nascosti" dietro un solo IP pubblico.

Terminologia Cisco

  • Inside Local: L'indirizzo IP assegnato all'host nella rete interna (es. 192.168.1.10).
  • Inside Global: L'indirizzo pubblico visto dall'esterno (assegnato dall'ISP).
  • Outside Global: L'indirizzo IP pubblico della destinazione (es. il server di Google).

Tipi di NAT

1. NAT Statico

Mappatura $1:1$ tra un IP privato e uno pubblico. Usato per i server interni che devono essere raggiungibili dall'esterno.

2. NAT Dinamico

Mappatura molti-a-molti. Il router ha un pool di IP pubblici e li assegna ai client interni finché sono disponibili.

3. PAT (NAT Overload)

È la forma più comune. Mappatura $N:1$. Molti IP privati usano lo stesso IP pubblico, distinguendosi tramite il numero di porta TCP/UDP.
